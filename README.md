# Sol paper desk

A read-only **paper trading** dashboard for three fake-money Solana memecoin books. Nothing here is a real trade, and the page cannot open, close, or change a position.

Live page: https://xenokynbot.github.io/sol-paper-dashboard/

The site updates about every minute. Figures can lag the books by about one to two minutes. The banner on the page says **Paper trading — fake money**.
